## Rules

- Tax rate for taxed items is a flat **8.25%**.
- Catalog values are current reference values only. A catalog-price change
  must never alter a saved, sent, approved, accepted, or historical
  estimate — always snapshot the unit cost into the estimate's cost row at
  the time it's used.
- "Stock Markup %" is a **default/reference** markup per item, distinct
  from the Estimate Cost Category default markup in
  `07-estimate-cost-categories.md`. Apply per-item markup at the cost-row
  level when the estimator uses a catalog item as-is; the estimator may
  still override price/markup on a project-specific basis with a reason
  per `02-estimator-workflow.md` STEP-013.
